# Evidencias pendientes de captura en navegador

No marcar una evidencia como completada hasta obtener una captura real, visible y verificable.

- [ ] Formulario de permiso con validaciones complejas (motivo/fechas/solapamiento).
- [ ] Flujo de aprobación: pendiente → aprobado.
- [ ] Django Admin con reportes y acciones masivas.
- [ ] Middleware de auditoría mostrando registros.
- [ ] Control de permisos jerárquicos (jefe de área).
- [ ] Sesión con timeout configurado (45 minutos).

La carpeta `capturas/` contiene documentación visual del código y del estado del proyecto generada desde los archivos fuente. No sustituye las seis capturas funcionales anteriores.
